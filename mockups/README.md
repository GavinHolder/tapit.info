# TapIt UI mockups

Design Component source files (`.dc.html`) for the TapIt UI concepts canvas.

**Version 2 (current): clean, calm, clickable**
- `Landing.dc.html` landing page with a live embedded app, working FAQ and sign-up form
- `App.dc.html` guest app phone prototype (tabs, sheets, search and filters, saving, replay, consent switch)
- `AppDesktop.dc.html` guest app desktop prototype
- `Portal.dc.html` business portal editor with live phone preview, blocks, save and publish
- `Network.dc.html` admin network overview (date range, chart hover, sortable table, detail drawer)
- `Scene.dc.html` shared animated 3D / 2D trip-route scene component

Older first-round boards (`Main`, `Guest`, `Trip`, `Profile`, `Club`, `Cms`, `Admin`, `Ledger`, `*Desktop`, `StyleLab`) are kept for reference.

To render locally, serve this folder with the Design Component runtime as `support.js`.
